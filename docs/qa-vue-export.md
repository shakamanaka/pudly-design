# Vue export QA

The Vue exporter consumes a validated `DesignDocument` and returns a portable Vite/Vue project. When registered with `BundledExporter`, it returns one ZIP download that preserves the relative project paths and includes a `fidelity-report.json`. The project contains the original semantic graph at `src/design-document.json`, a render tree derived from that graph at `src/design-tree.json`, a responsive runtime renderer, and the pinned app scaffold. Generated names and paths are fixed by the adapter and never come from document values.

Extract the ZIP, then run `npm install`, `npm run dev`, or `npm run build` from the exported project directory. `BundledExporter` rejects absolute, traversal, backslash, NUL, and duplicate paths before creating the archive. The Vue runtime uses Vue text interpolation and bound attributes for design values; document values are kept in JSON artifacts and are not spliced into executable source or markup.

Fidelity is reported per node and feature. Layout, sizing, semantic color/spacing/radius/typography/shadow tokens, vectors, and breakpoint rules are rendered from the source graph. A component instance is resolved from its definition, selected variant, bound properties, node overrides, and anchored slots, then expanded into render nodes. The original reusable component graph remains available in `design-document.json`; because the static app has no component editing workflow, this expansion is reported as degraded. Images and icons show accessible placeholders because a `DesignDocument` holds asset/library identifiers but does not contain their binary assets. A conflicting center and edge anchor falls back to the center anchor and is reported as degraded.

`tests/export/vue-export.test.ts` covers app artifacts and pinned dependencies, responsive runtime inclusion, JSON-only handling of script-like user strings, component binding and slot expansion, per-node fidelity diagnostics, and rejection of unsupported document versions. `tests/export/vue-bundle.test.ts` opens the actual ZIP with `fflate` and checks its nested files, embedded design graph, fidelity report, partial status propagation, and unsafe-path rejection. An isolated Vite build of the returned project remains a separate check.
