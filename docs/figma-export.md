# Figma export QA

The Figma adapter reads a validated `DesignDocument` and generates a plain Plugin API script from its semantic graph. It does not inspect Vue, HTML, DOM, or screenshots. The callable `buildFigmaScript(document, targetPageId?, viewportWidth = 1440, semanticPageId = document.pageOrder[0])` targets the current Figma page when `targetPageId` is omitted; when supplied, it resolves and switches to that Figma page once. The semantic page ID is separate from Figma's target-page ID. One semantic page is written per call, and the script returns created target IDs, source mappings, node/text/root counts, root bounds, and the fonts Figma actually accepted.

The direct script uses top-level `await` and `return` for the `use_figma` runner. Text is created only after `listAvailableFontsAsync()` discovers a supported family/style and `loadFontAsync()` completes. Text line height is a unitless ratio in the source model, so a 24px font with a 1.25 ratio is emitted as 30px. New page roots are placed to the right of existing content. The script does not tag or delete existing layers. Values are embedded with JSON serialization and `<`, U+2028, and U+2029 escaping; SVG path text is additionally XML-escaped.

The downloadable artifact from `FigmaExporter` is `codex-design-figma-plugin.zip`, a developer-plugin starter bundle with `manifest.json`, `code.js`, setup `README.md`, and the complete `design-document.json`. Its generated `code.js` wraps the semantic script for normal Figma plugin execution and closes the plugin after a successful import. Figma assigns plugin IDs; the generated manifest contains an explicit placeholder, and the archive README explains creating a development plugin and preserving its assigned ID before import. This setup requirement is returned as a warning. See [Figma manifest documentation](https://developers.figma.com/docs/plugins/manifest/). Offline export always reports `partial` and includes `export.figma.live-write-unverified`: creating this archive does not create or update a Figma file.

The mapper creates frames with auto layout, places free-layout children by their semantic positions, applies fills/colors including alpha, opacity, corner radius, typography, alignment, and vectors. Component instances are expanded from the selected variant, effective properties, node overrides, and slot children. The instance's position, dimensions, visibility, and style override are applied to the component template root without an extra layout wrapper. Components remain ordinary editable layers; the native JSON carries the original component definitions. Vector paths are imported as SVG geometry inside a Figma wrapper frame. Groups also become frames.

The fidelity report marks token values as flattened (not Figma variables/styles), responsive rules as degraded to their selected-viewport state, and reusable components/groups/vectors as degraded. Image and icon nodes are omitted because their binary/library assets are absent from the source document. Shadow tokens and anchor constraints are retained in source JSON but are not emitted as target effects/constraints. Extra semantic pages are omitted from a single-page script run. Font families and named weights may fall back to a style Figma reports as installed; the returned `fonts` and `warnings` arrays expose the actual choice. The archive never reports full fidelity.

`tests/export/figma-export.test.ts` covers direct script shape and JSON-safe user text, plugin ZIP contents and partial-fidelity reporting, unsupported responsive/constraint/token cases, fixed component-instance bounds and overrides, and execution of the generated script against a focused Plugin API mock. The mock verifies the emitted title has 24px font size and 30px line height and that the returned IDs, SVG descendants, and bounds match the nodes created by the script. Connected Figma file creation and visual validation are separate integration evidence and must be recorded by the agent that performs that live write.

Connected validation passed in [the verification file](https://www.figma.com/design/IWyN9dZuDRc8rqhpbBFf54?node-id=3-2): root `3:2` has five editable layers, three text nodes, 360×254 bounds, no font fallback warnings, and a visually inspected screenshot. The 24px title has 30px line height. This verifies the semantic write path; it does not turn the offline browser download into a live authenticated export.
