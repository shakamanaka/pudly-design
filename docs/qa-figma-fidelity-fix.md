# Figma component-template fidelity correction

The Figma fidelity report now gives every emitted component-template kind a feature entry for its name, visibility, layout mode, width and height sizing, alignment, and applicable spacing/padding and style values. Text templates report content, alignment, and typography; vectors report their wrapper-based geometry import; constraints, responsive rules, and shadow tokens report their actual loss or flattening. Template roots and children whose sizing cannot be applied identify the target's 100px/content default or the missing auto-layout parent. Image and icon templates report omission and asset loss only because the importer creates no layer for them.

The feature statuses follow `__make` in `src/adapters/export/figma.ts`: names and visibility are always assigned; colors, opacity and frame radius are conditional; auto-layout consumes alignment, spacing and padding; text content/alignment/font settings are applied with font fallback; vectors use SVG geometry in a wrapper frame; constraints and shadow effects are not applied. Template fidelity entries remain keyed by component and template IDs, while the broad component-definition entry continues to describe flattened reuse.
